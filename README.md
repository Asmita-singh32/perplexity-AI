# Perplexity AI

An AI-powered search application that helps users explore information and get answers through an interactive search experience.

## Features
- AI-powered question answering
- Interactive chat interface
- User authentication
- Responsive frontend
- Backend API integration

## Tech Stack
- **Frontend:** React, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** Add your actual database here
- **AI Integration:** Add the AI API or model you actually use

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Asmita-singh32/perplexity-AI.git
cd perplexity-AI
```

### 2. Install dependencies
Install dependencies separately inside the `Backend` and `Frontend` folders.

```bash
cd Backend
npm install
```

```bash
cd ../Frontend
npm install
```

### 3. Configure environment variables
Create a `.env` file in the required project folders and add your API keys and configuration. Never commit secrets to GitHub.

### 4. Run the application
Follow the start scripts defined in each folder's `package.json`.
